### What I've built

**[PharmaStackX](https://github.com/Surge-Ogiemudia/pharmastackx-case-study)**: a connected platform for pharmacies, made of four products that share one data layer.

| Product | What it does |
|---|---|
| **Marketplace** | Patients search for a medicine and see which nearby pharmacies have it in stock, then order or request it. |
| **POS** | Multi-tenant point of sale for pharmacy branches and bulk stores, with stock deducted atomically on every sale. |
| **EMR** | Pharmacy-level consultations and patient records, linked to the POS at the point of dispensing. |
| **Synkk** | A desktop app that reads stock from the software a pharmacy already uses and syncs it to the marketplace. |

→ **[Read the case study](https://github.com/Surge-Ogiemudia/pharmastackx-case-study)** for the architecture, the hard problems I solved, and how it's secured.
