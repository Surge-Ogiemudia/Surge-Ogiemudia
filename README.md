### Selected work

**[PharmaStackX](https://github.com/Surge-Ogiemudia/pharmastackx-case-study)**: four connected products running in production, sharing one data layer.

| | |
|---|---|
| **Point of sale** | Multi-tenant, with isolated data per business, branch and store. Stock is deducted inside a database transaction on every sale. |
| **Records management** | Structured records with sign-on shared across the platform and signed share links. |
| **Desktop sync agent** | Electron app that reads data from whatever software a site already runs and syncs it to the cloud. |
| **Marketplace** | Live search across every connected location, with orders, payments and delivery. |

→ [Read the case study](https://github.com/Surge-Ogiemudia/pharmastackx-case-study) for the architecture and the hard problems I solved.
